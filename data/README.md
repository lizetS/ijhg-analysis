# Input data

The health-area-level COVID-19 surveillance data are the property of the Cuban Ministry of
Public Health (MINSAP). They are not redistributed here. This file lists what the pipeline
expects so that the analysis can be reproduced by anyone who obtains the same inputs.

## Required files (restricted data)

```
data/raw/habana_panel_corregido.xlsx
data/raw/shapefiles/AS_vuln_vs_casos_8_periodos.shp   (+ .dbf .shx)
data/raw/shapefiles/otras variables/AS_con_enlace_lista.shp   (+ .dbf .shx)
data/raw/covid_cases_havana_until_311222.xlsx         (daily line list; wave robustness)
data/raw/serie.xlsx                                   (daily series; Figure 1)
```

### The corrected panel (`habana_panel_corregido.xlsx`)

Sheet `panel_corregido`: one row per health area and epidemic wave (82 areas × 7 waves = 574
rows). Fields used by the pipeline:

| Field | Meaning |
|---|---|
| `codigo_as` | health-area code, 1–82 (matches `Etiqueta` in the shapefiles) |
| `covid_variant` | wave: `Wuhan1`, `Wuhan2`, `D614G`, `Beta`, `Delta`, `Omicron1`, `Omicron2` |
| `cases_per_variant` | confirmed cases in the area and wave |
| `deaths_per_variant` | deaths in the area and wave |
| `poblacion` | population denominator (2,317,226 across the 82 areas) |
| `density_corrected` | population / polygon area |
| `hacin_panel_original` | crowding: residents per bedroom (primary definition) |
| `Prop_Hip` … `Prop_Asma` | chronic-disease prevalence, corrected counts / population |
| `Dist_x_AS`, `Dis_x_CMF_A`, `ageing_index_cub`, `mayores60`, `vacunados` | see the dictionary |
| demographic, housing and socioeconomic fields | see `docs/DATA_DICTIONARY.md` |

The workbook also contains the sheets `cambios` and `pendientes`, which document every
correction made to the original panel and the points still open. The original file
(`habana_covid_integration_by_variant_Wave_310825.xlsx`) is **not** used: several of its
covariate columns are attached to the wrong health area. See `docs/CORRECTIONS.md`.

### The shapefiles

* `AS_vuln_vs_casos_8_periodos.shp` — the 82 health-area polygons, with the area code
  (`Etiqueta`) and name (`ASalud`). The file has no `.prj`; coordinates are metric (UTM-like)
  and the total area of the 82 polygons is about 718 km², consistent with Havana.
* `otras variables/AS_con_enlace_lista.shp` — census aggregates per health area: precarious
  housing (`Ave_PcVivD`), equipment-to-resident ratio (`Ave_EquipD`), education
  (`Ave_GradxE`) and piped-water access (`Ave_PcAAgu`). Joined by `Etiqueta`.

## Synthetic test dataset (included)

`data/synthetic/` contains a simulated dataset with the same structure and file names as the
restricted inputs:

```
data/synthetic/habana_panel_corregido.xlsx      corrected-panel schema (574 rows)
data/synthetic/shapefiles/AS_vuln_vs_casos_8_periodos.shp
data/synthetic/shapefiles/otras variables/AS_con_enlace_lista.shp
data/synthetic/covid_cases_havana_until_311222.xlsx
data/synthetic/serie.xlsx
```

It is generated by `tools/make_synthetic_data.R`: the geography is a Voronoi tessellation of
a 30 x 24 km rectangle, and every covariate and outcome is simulated. It is intended for
testing the code, not for inference. `config.R` uses it automatically when the real panel is
absent from `data/raw/`.
